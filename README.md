# FolkTuk

**Folks, Gather Here. Let’s Talk!**  
*Connect. Converse. Belong.*

FolkTuk is an independent global social network built around three equally important pillars:

1. Social Connection
2. Communities
3. Opportunities

The initial architecture is a modular monolith. The proposed stack is Next.js, React, and TypeScript for the frontend; NestJS and TypeScript for the backend; and PostgreSQL for the database. See the [project baseline](docs/PROJECT_BASELINE.md) and [open decisions](docs/OPEN_DECISIONS.md) for details.

Implementation will proceed in controlled milestones. Proposed technologies and unresolved decisions will be validated before they are treated as finalized.
